Pipeline Text Preprocessing (NLP)

1. Case Folding: Mengubah seluruh karakter ke huruf kecil (lowercase)
2. Text Cleaning: Menghilangkan tautan URL, angka, simbol, tanda baca, & emoji
3. Tokenizing: Memisahkan string teks menjadi deretan token kata
4. Normalization: Mengganti kata slang/bahasa daerah ke bentuk kata baku Bahasa Indonesia
5. Stopword Removal: Menghapus kata umum yang tidak memiliki bobot sentimen
6. Stemming (Sastrawi): Mengembalikan kata berimbuhan ke kata dasar
7. TF-IDF Vectorizer: Menghitung pembobotan frekuensi kata untuk input model
