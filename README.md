# 🌐 Portofolio Profesional Web | IT Support & Administrasi IT
### Mochamad Shcamsul Sieddik Permana (S1 Teknik Informatika - Institut Digital Ekonomi LPKIA Bandung)

Website portofolio modern, responsif, dan interaktif yang dibangun secara khusus dengan standar visual terkini (*Bento Grid*, *Glassmorphism*, *Cyber Terminal Emulator*, serta *Print-Ready CV PDF*).

---

## ✨ Fitur & Tampilan Visual Unggulan

1. **Desain Visual & Estetika Kelas Industri**:
   - **Bento Grid Architecture**: Tata letak modular dengan frosted glassmorphism dan border glow interaktif.
   - **Live Interactive Terminal**: Emulator shell di Hero section yang mensimulasikan pengecekan status sistem, pengujian ping jaringan, status deployment sistem E-Report, dan akurasi model data mining Decision Tree.
   - **Candidate Verified Card**: Menampilkan foto asli kandidat (`assets/images/profile.jpg`) dengan ring status aktif (*Open to Work*).
   - **Tipografi Modern**: Memanfaatkan perpaduan font *Space Grotesk*, *Plus Jakarta Sans*, dan *JetBrains Mono*.

2. **Konten Terstruktur Sesuai Pengalaman Nyata**:
   - **Profil & Nilai Profesional**: 3 pilar kerja utama (Kemauan belajar, Teliti & terstruktur, Kolaboratif & taat SOP).
   - **Pengalaman Magang**:
     - **PT Primasaga Strategic**: IT Support & Web System Intern (troubleshooting hardware/software, pengembangan website E-Report, pengelolaan basis data MySQL).
     - **LSP GMBE**: Administrasi IT & Data Support Intern (verifikasi & rekapitulasi 1.200+ berkas asesi uji kompetensi dengan advanced Excel VLOOKUP/Pivot).
   - **Proyek Pilihan**:
     - **01 | Sistem Laporan Kegiatan Karyawan (E-Report - PKL)**: Berbasis Agile Scrum 4-Sprint, PHP/MySQL, dengan mockup dashboard mini interaktif.
     - **02 | Analisis Sentimen Ulasan Aplikasi Persib (Skripsi Data Mining)**: Metodologi CRISP-DM 6 tahap, preprocessing NLP Sastrawi, dan evaluasi Decision Tree (akurasi 86.4%).
   - **Keterampilan & Level Meter**: Filter interaktif 4 area (IT Support, Administrasi IT, Tools & Office, Teknis/Data).
   - **Pendidikan**: Sarjana (S1) Teknik Informatika, Institut Digital Ekonomi LPKIA Bandung, Lulusan 2026.

3. **Fitur Interaktif Canggih**:
   - ✏️ **Modal Kustomisasi Data Portofolio**: Pengguna dapat mengubah nama, email, no HP, kampus, prodi, dan bio secara langsung melalui tombol "Kustomisasi Data Saya" di browser tanpa perlu mengedit kode manual. Data tersimpan otomatis di `localStorage`.
   - 🌓 **Dark Mode / Light Mode**: Tombol peralihan tema otomatis dengan penyimpanan preferensi.
   - 🖨️ **Cetak CV / Ekspor PDF**: Dilengkapi stylesheet print khusus (`@media print`) yang menyembunyikan tombol navigasi dan merapikan halaman menjadi dokumen CV siap cetak/kirim.
   - 📋 **Salin Kontak Satu Klik**: Tombol salin email dan nomor WhatsApp dengan notifikasi toast.
   - 🔍 **Modal Rincian Proyek**: Penjelasan alur metodologi Agile Scrum 4 Sprint & alur 6 tahap CRISP-DM.

---

## 🚀 Cara Menjalankan Website

1. Buka folder kerja di File Explorer komputer Anda.
2. Klik dua kali file `index.html`.
3. Website akan langsung terbuka di browser favorit Anda (Google Chrome, Microsoft Edge, Brave, Mozilla Firefox).
